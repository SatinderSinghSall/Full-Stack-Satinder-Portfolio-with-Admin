# Satinder Portfolio — Full-Stack Portfolio CMS Platform

## Overview

Satinder Portfolio is a modern production-grade Full-Stack Portfolio & Content Management Platform engineered to demonstrate real-world frontend architecture, backend systems, CMS workflows, cloud integrations, authentication pipelines, and scalable application engineering.

The project is designed not as a static portfolio website, but as a complete dynamic platform capable of managing:

- Portfolio Projects
- Blog Content
- Freelance Work
- YouTube Content
- AI/ML Showcase
- Contact Management
- Admin Dashboard Operations
- Media Upload Pipelines

The platform combines modern frontend engineering with scalable backend architecture to simulate production SaaS-style workflows.

---

# System Architecture

## Frontend Architecture

The frontend is built using:

- React 19
- Vite 7
- Tailwind CSS v4
- Framer Motion
- React Router DOM v7
- EditorJS
- Radix UI

The frontend follows a component-driven architecture with reusable UI systems and modular route organization.

### Frontend Structure

```bash
frontend/src/
│

```

## Content Rendering Pipeline

Workflow:

1. Admin creates blog content
2. EditorJS generates structured block JSON
3. Backend stores JSON in MongoDB
4. Frontend fetches blog data
5. Custom block renderer dynamically renders content

# Authentication Workflow

Authentication uses JWT-based authorization.

## Login Flow

1. Admin submits credentials
2. Backend validates credentials using bcrypt
3. JWT token generated
4. Token stored on frontend
5. Protected APIs require token validation

---

# Media Upload Pipeline

The platform integrates Cloudinary for cloud media management.

## Upload Flow

1. User uploads image from dashboard
2. Multer processes multipart form data
3. Cloudinary storage middleware uploads image
4. Optimized media URL returned
5. URL stored in MongoDB
6. Frontend dynamically renders image
